# HP419A-LED-neon-replacement-board
HP419A LED neon Replacement board (based on Mr.Carson's lab design)
This board replaces the neons in a HP419A, as well as the oscillator circuit, should be powered by the + - 13v (battery + battery - lines )

You will have to adjust led current based on your LED, with mine os5rpm57e1a (https://www.tme.eu/it/details/os5rpm57e1a-mn/diodi-led-tht-rotondi/optosupply/) i settled on powering them with 2.5K ohm in series.
